## 앱 이름: [눈 건강 지킴이]

## 카테고리: [페어 프롬프트 릴레이]

### 배포 링크

https://gemini.google.com/share/9fad003152a5

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
- 코딩을 할 때 눈을 굉장히 오래 뜨고 있는 문제가 있다. 이는
  코딩 지속력에 아주 큰 영향을 끼친다.
- 이 앱을 언제, 어떻게 사용할 건가요?
  코딩이나, 게임을 시작하기 전 띄워두면 아주 좋을 것 같다.
  눈건강을 지킬 수 있다. 또한 눈을 오래 감고 있을 시 졸음 방지를 할 수 있는
  알람 기능 또한 있다.

### 주요 기능

- 기능 1 : 총 눈 깜빡임 횟수 받기.
- 기능 2 : 분당 눈깜빡임 계산 후 사용자 알림
- 기능 3 : 눈을 오래 감고 있을 시 졸음 방지 알람
