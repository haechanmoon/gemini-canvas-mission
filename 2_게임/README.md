### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
- 우리나라 국가대표 경기 불황. 이에 대한민국 축구의 발전을 기원하며 앱을 만들어봤습니다.

- 이 앱을 언제, 어떻게 사용할 건가요?
- 주요 A매치가 있을 때 전후에 해보면 경기 보는 맛이 더 살아날 것 같습니다. 당일 선발 멤버를 직접 투입시켜보는 것도
  좋은 방법이 될 것 같습니다.
